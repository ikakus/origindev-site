Border + shadow pulse. Use for live indicators, active states, focus rings.

Opacity flicker at random interval. Use for error states, unstable signals, loading.

Cyan glow oscillation. Use for scanning states, background ambient effects.

Step-function border blink. Use for cursor indicators, terminal prompts, timers.
